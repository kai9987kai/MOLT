# Influence map

MOLT is an original small-scale implementation informed by the linked projects. It does not copy or bundle their source code, weights, datasets, or art. “Implemented” below means a design idea shaped this prototype; it does not mean that MOLT reproduces the source project's scientific or technical system.

| Project | Influence on MOLT | Boundary in this version |
| --- | --- | --- |
| [NexusSearch](https://github.com/kai9987kai/NexusSearch) | Searchable seed-by-arm records with explicit fields and reproducible local exports. | A small in-browser exact-filter ledger; no C engine, ANN, or vector search. |
| [prometheus-alpha](https://github.com/kai9987kai/prometheus-alpha) | Paired versus unpaired cue learning, head removal, regrowth, and memory-retention readouts. | A twelve-cell abstract state model, not a neural cellular automaton or a biological experiment. |
| [3d-animal-simulator-Hybrid-Agent](https://github.com/kai9987kai/3d-animal-simulator-Hybrid-Agent) | Seeded interventions and an ecology-facing outcome rather than stopping at a tissue score. | Two-dimensional Canvas and a fixed resource pool; no 3D terrain, animal behaviour model, or field calibration. |
| [morpheus](https://github.com/kai9987kai/morpheus) | Memory can be distributed across body cells and manipulated by grafting a matched twin's state. | “Trace” is a regularized numeric association. There is no membrane-voltage diffusion, trained cell rule, or morphogenesis. |
| [Supermix-Expanse-v2](https://github.com/kai9987kai/Supermix-Expanse-v2) | Keep components and evaluation claims separable; record when a comparison is weak or unresolved. | No language model, donor checkpoint, biomedical data, or model promotion pipeline is included. |
| [GhostInTheMachine](https://github.com/kai9987kai/GhostInTheMachine) | Expose prediction error as an internal model diagnostic while keeping claims bounded. | Brier score is a toy controller's forecast check; there is no authorship experiment and no consciousness measure. |
| [Supermix-expanse](https://github.com/kai9987kai/Supermix-expanse) | Treat heterogeneous parts as explicit components with distinct roles instead of implying that a single blended score explains the result. | No parameter grafting, distillation, connectome, or trained inference model. |
| [GenesisEngine](https://github.com/kai9987kai/GenesisEngine) | Keep simulation logic deterministic and separate from its renderer; make seeds the experiment unit. | The body is assigned a fixed twelve-cell layout. Single-cell development, regulatory genomes, and reproduction are future work. |
| [supermix-archimedes](https://github.com/kai9987kai/supermix-archimedes) | Modular composition and explicit source boundaries inform how tissue, policy, world, and readout are kept as separate stages. | No neural grafts, 22-brain controller, multimodal model, or checkpoint is ported. |
| [Supermix](https://github.com/kai9987kai/Supermix) | Local-first tooling and an evidence-aware experiment surface. | MOLT has no chat runtime, training stack, or external service integration. |
| [FLY-DIAMOND-NEXUS](https://github.com/kai9987kai/FLY-DIAMOND-NEXUS) | Shared-world interaction makes individual choices affect group access to finite resources. | Cohort agents use a small fixed policy, not the Fly Lab's specialised neuropils, spiking circuits, or learned synapses. |
| [QuantumBot](https://github.com/kai9987kai/QuantumBot) | Matched random streams and fair comparisons of competing policies are central to the experiment design. | The PRNG is classical. There is no variational circuit, quantum hardware, quantum-advantage claim, or policy evolution. |

## What MOLT adds as a research direction

The intended cross-scale chain is **where the trace survives → what the regrown organism does → who reaches shared resources → which cohorts remain alive**. Tissue state, cue validity, and food availability are all controlled by the simulation, so the app can explore how the model's assumptions produce downstream outcomes. That makes it a hypothesis-generating sandbox, not evidence that the same causal chain operates in nature.

The combination is new to this project. This document is not a systematic review and does not establish that the underlying idea is unprecedented.
